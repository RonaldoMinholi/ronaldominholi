# Olá, eu sou Ronaldo Minholi 👋

Crio soluções práticas com apoio de inteligência artificial, unindo dados, automação e ferramentas visuais para resolver problemas reais.

Atuo principalmente na definição, organização, testes e evolução de projetos como:

- Painéis de indicadores e acompanhamento de dados
- Sistemas web para organização e gestão de projetos
- Integrações com APIs e ERPs
- Automação de processos e relatórios
- Modelagem e projetos para impressão 3D

Não me apresento como desenvolvedor tradicional. Uso IA como ferramenta de trabalho para transformar necessidades em soluções funcionais, participando ativamente das decisões, validações e melhorias de cada projeto.
